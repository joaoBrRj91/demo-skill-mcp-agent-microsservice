- 2026-06-09: `Class1.cs` placeholder files exist in Domain, Application, and Infrastructure.Data — likely generated by `dotnet new classlib` and never removed.
- 2026-06-09: ReDoc UI is served via `Swashbuckle.AspNetCore.ReDoc` (V005). The JSON spec is produced natively by `Microsoft.AspNetCore.OpenApi`. This is a mixed approach; rule P4 requires avoiding Swashbuckle entirely.
- 2026-06-09: `DeleteCatalogProductCommandHandler` constructs `new CatalogProductId(cmd.Id)` directly (line 13). This is permitted — constructing a strongly-typed ID wrapper is not the same as bypassing an aggregate `Create()` factory. Rule A3 does not apply here.
- 2026-06-09: `Infrastructure.Integration` has no `CatalogProductCreatedConsumer` at all; the `EntityCreatedConsumer` covers only the `Entity` aggregate.
- 2026-06-09: The approved pattern for the ReDoc UI is a self-contained `app.MapGet("/docs", ...)` in `Program.cs` returning static HTML that loads the ReDoc CDN bundle. This does not violate P1 (it is not a business endpoint) and fully satisfies P4 (no Swashbuckle dependency).
